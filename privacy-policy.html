Rozsah těchto zásad

Údaje na tomto webu

Web je tvořen statickými HTML a CSS soubory. Neobsahuje registraci, kontaktní formuláře, reklamy ani analytické či sledovací skripty. Kód webu nenastavuje cookies ani neukládá údaje do úložiště prohlížeče.

Hosting na GitHub Pages

Web hostuje služba GitHub Pages. Při návštěvě GitHub zpracovává technické údaje potřebné k doručení a zabezpečení webu, například IP adresu. Podrobnosti o zpracování, uchovávání údajů a vašich právech najdete v zásadách ochrany soukromí GitHubu.

Odkazy na jiné weby
