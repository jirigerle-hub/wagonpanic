# Wagon Panic

Jednoduchá česká HTML stránka železniční logické hry Wagon Panic s odkazem na
`privacy-policy.html`. Bez JavaScriptu, externích knihoven nebo sestavení.

Privacy Policy popisuje pouze tento informační web a hosting na GitHub Pages,
nikoli mobilní aplikaci.

## Spuštění

Otevřete `index.html` přímo v prohlížeči, nebo v kořenové složce spusťte:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Web bude dostupný na <http://127.0.0.1:8000>. S nainstalovaným npm lze použít
také `npm start` (vyžaduje Python 3). Žádná instalace balíčků ani sestavení není potřeba.
